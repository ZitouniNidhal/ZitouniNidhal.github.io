A Modular Multi-Omics Data Integration Framework for Precision Oncology Using Explainable AI

Nidhal Zitouni, Mohsen Maraoui

This paper presents a modular framework for integrating heterogeneous multi-omics data (genomics, transcriptomics, proteomics) for cancer subtype classification. The framework employs deep learning feature encoders combined with SHAP-based explainability layers, enabling oncologists to trace model predictions back to biologically meaningful features. The pipeline follows FAIR data principles for reproducibility and interoperability across clinical datasets.

A Scalable and FAIR-Compliant Multi-Omics Integration Pipeline for Clinical and Genomic Data

Nidhal Zitouni, Mohsen Maraoui

This work describes a scalable, standards-compliant data integration pipeline designed to handle large-scale clinical and genomic datasets. The system harmonises multi-omics inputs using ontology-based normalisation and provides AI-ready data outputs for downstream machine learning tasks. Benchmarked against real-world oncology cohorts to validate scalability and FAIR compliance (Findable, Accessible, Interoperable, Reusable).
